## Core CherryTree Features

- **A Node Tree:** Keep notes under headings you name, so a long list is not one endless page.
- **Rich or Plain Text:** Write the way the note needs. A checklist and a paragraph can live in different nodes.
- **One File or a Folder:** The notebook is a document you can copy. Know whether you saved a single file or a directory of nodes.
- **Search:** Find a title or a phrase you wrote, instead of scrolling every branch.

---

## About CherryTree

CherryTree is a notebook for text you write: project notes, a procedure you follow, or a personal log. It does not subscribe you to a cloud, and it does not import someone else's private notebook just because the file was on a shared disk. If you sync the file yourself, that copy is only as private as the place you put it.

The tree is the map. A node with a clear name is easier to find than a clever one you will not remember. Search still matters when the tree gets deep. Passwords do not belong here unless you accept that this file is now as sensitive as a password list. A password manager is the better place for logins.

Export or copy the notebook before you experiment with a format change. A conversion you do not like is annoying when the only copy was inside that experiment.

## Tool Benefits

- **Local First:** The notes exist as a file you can back up without an account.
- **A Readable Structure:** Nodes keep topics apart.
- **A Real Backup:** Copying the file or the folder is the spare. The program is not the archive.

## Getting Started with CherryTree

Prerequisites: A place to save the notebook, and text you are willing to type yourself.

1. **Create a Notebook:** Save it where you will find it after a reinstall.
2. **Add One Node:** Give it a plain title and a few sentences.
3. **Search That Title:** Confirm the note comes back.
4. **Copy the File:** Put a spare on another disk before you rely on the tree.

---

## Professional & Personal Use Cases

- **A Personal Procedure:** Steps you repeat, written once and updated when the steps change.
- **A Project Scratchpad:** Decisions and links in nodes, not in ten chat threads.
- **A Backup Habit:** The notebook file copied whenever you add something you would hate to retype.
- **A Shared PC:** Close the file and do not leave it in a public folder.
